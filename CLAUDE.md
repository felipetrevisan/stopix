# Stopix

## Regras do projeto

- **Nada técnico em texto do frontend.** Nunca mostrar para o usuário nomes de
  tecnologias ou serviços de infraestrutura (Firebase, Vercel, Next, React…), nomes de
  variáveis de ambiente, chaves, caminhos, códigos de erro ou termos de programação.
  Mensagens de erro e avisos falam a língua de quem joga ("As salas online estão
  indisponíveis no momento"). Detalhes técnicos vão só para `console.error` e para o
  README. Produtos que o usuário usa de verdade (Neon Live Labs, TikTok LIVE Studio,
  OBS) podem aparecer nas instruções do painel da live.
- Textos da interface em português do Brasil.
- Rodar `bun run check` antes de commitar.
